🔍 SharedArrayBuffer Diagnostic Test

What This Tests

This page checks if SharedArrayBuffer is available in your browser. SharedArrayBuffer is required for FFmpeg.wasm multi-threaded processing (faster video encoding).

Requirements

  • Browser must support SharedArrayBuffer
  • Page must be served with proper HTTP headers:
    • Cross-Origin-Opener-Policy: same-origin
    • Cross-Origin-Embedder-Policy: require-corp
  • Page must be accessed via HTTP/HTTPS (not file://)
