🔍 Server Headers Check

This page checks if the server is sending the correct headers for SharedArrayBuffer.

Manual Check

Open browser DevTools (F12) → Network tab → Refresh this page → Click on this page's request → Headers tab

Look for these headers in the Response Headers:

  • Cross-Origin-Opener-Policy: same-origin
  • Cross-Origin-Embedder-Policy: require-corp
